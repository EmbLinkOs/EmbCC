# C conformance corpus for -std= (tests/golden/std-modes.sh).
#
# Each case is a name line `== NAME` and the C source after it, up to the
# next case. tools/std-expect.sh compiles every case under every C mode,
# with and without -pedantic-errors, with GCC (the referee), and records
# whether GCC accepted it in tests/std/c-expect.txt; std-modes.sh holds
# EmbCC to that record. A case uses no header but GCC's freestanding ones.
