# C++ conformance corpus for -std= (tests/golden/std-modes.sh).
#
# As tests/std/c-corpus.txt, for C++: each case is a name line `== NAME`
# and the source after it, up to the next case. tools/std-check.py
# compiles every case under every C++ standard from c++98 to c++26, with
# and without -pedantic-errors, with GCC (the referee) and with EmbCC; the
# referee's outcomes are tests/std/cxx-expect.txt. No case includes a
# header.
